yumcha.core.exceptions module

Exception hierarchy for phonological rule processing and scheme execution errors.

Provides custom exception classes to handle domain-specific errors such as rule violations, unresolved pattern queries, and unsupported scheme operations.

Coordinates phonological representations and orthographic/romanization schemes.

Provides high-level APIs for converting phoneme representations to/from registered schemes, cross-converting between schemes, running validations, and generating combinatorial syllable tables.

convert_intermediate_to_scheme(source, scheme_id, validate=True, strict=True, solver_id=None)[source]

Converts intermediate phonological input into a scheme representation.

Overloads:

  • self, source (str), scheme_id (str), validate (bool), strict (Literal[True]), solver_id (Literal[SupportedSolvers] | None) → SchemeRepresentation

  • self, source (str), scheme_id (str), validate (bool), strict (Literal[False]), solver_id (Literal[SupportedSolvers] | None) → SchemeRepresentation | None

Parameters:

  • source (str) – Source string in intermediate phonology format.

  • scheme_id (str) – Identifier of the registered target scheme to convert into.

  • validate (bool) – Whether to run phonotactic rules and roundtrip validation.

  • strict (bool) – If True, raises exceptions on validation failure or missing solver solutions. If False, returns None instead.

  • solver_id (Optional[Literal[SupportedSolvers]]) – Identifier of the solver to resolve source text into a solution. If None, picks the default solver from self._solver_to_use.

Returns:

An instantiated target SchemeRepresentation dataclass, or None if strict=False and conversion/validation fails.

Raises:

  • ValueError – If no valid solver solution exists and strict=True.

  • PhonologicalError – If the input violates phonotactic rules and strict=True.

  • NotSupportedError – If roundtrip validation fails and strict=True.

  • KeyError – If scheme_id is not registered, or if solver_id is not in self._solvers.
