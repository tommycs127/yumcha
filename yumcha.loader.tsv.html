yumcha.loader.tsv.reader module

Low-level file and stream reader utilities for TSV format input.

yumcha.loader.tsv.reader.read(source, encoding='utf-8', newline='')[source]

Reads and parses a TSV (tab-separated values) file or stream into headers and data rows.

Supports reading from file paths (string or Path), Traversable resource objects, or open text streams (IO[str]).

Parameters:

  • source (Union[str, Traversable, IO[str]]) – File path, Traversable resource, or open readable text stream.

  • encoding (str) – Text encoding to use when opening file paths or traversables. Defaults to “utf-8”.

  • newline (str) – Newline processing control when opening files. Defaults to “”.

Returns:

  • headers: A list of strings representing the header row.

  • data: A list of rows, where each row is a list of cell string values.

Return type:

tuple[list[str], list[list[str]]]

Raises:

ValueError – If the file or stream contains no non-empty rows.

yumcha.loader.tsv.load_language(language_id, directory=None, phonology_file_name='phonology.tsv', schemes_folder_name='schemes')[source]

Loads a full language representation along with its phonology and scheme specs.

Parameters:

  • language_id (str) – Identifier of the language directory to load.

  • directory (str | Traversable | None) – Optional root directory containing language specs. Defaults to yumcha.data.

  • phonology_file_name (str) – Filename for the phonology TSV file. Defaults to “phonology.tsv”.

  • schemes_folder_name (str) – Subfolder name containing scheme TSV files. Defaults to “schemes”.

Return type:

Language[PhonologyRepresentation]

Returns:

A populated Language object containing phonology and associated schemes.

Raises:

  • ReadError – If reading any TSV file fails due to I/O issues.

  • ParseError – If parsing any TSV file content fails due to validation errors.
