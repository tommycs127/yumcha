Data representations for phonological features and schemes.

Provides abstract and base dataclass containers for feature structures, enabling normalized string generation and iteration over field slots.

class yumcha.core.models.representation.Representation[source]

Bases: Iterable[str]

An abstract immutable container representing feature structures.

Subclasses define fields corresponding to individual features or phonological slots. Iterating over a Representation yields the value of each field in definition order.
