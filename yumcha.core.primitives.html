class yumcha.core.primitives.pattern_tuple.PatternTuple(iterable)[source]

Bases: Sequence[Pattern]

A bitmask-accelerated immutable sequence container for characters/patterns and wildcards.

PatternTuple tracks populated string slots versus empty wildcard (Ellipsis) slots using integer bitmasks (mask). This structure optimizes fast matching, merging, filtering, and intersection operations across fixed-length pattern sequences.

mask

A bitmask integer where bit i is set (1) if slot i contains a concrete string value rather than an ellipsis.

Type:

int

weight

The Hamming weight or bit count of mask.

Type:

full_mask

A precomputed bitmask representing total mask where all slots up to length len(self) are set to 1.
