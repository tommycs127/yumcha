yumcha.core.utils.bit module

Bitwise manipulation and iteration utilities.

Provides functions for efficient operations on integer bitmasks using algorithms such as Brian Kernighan’s bit-counting method.

yumcha.core.utils.bit.iterate_bits(mask, yield_lowest_bit=False)[source]

Iterate over set bits (`1`s) in a non-negative integer mask.

Overloads:

  • mask (int) → Iterator[int]

  • mask (int), yield_lowest_bit (Literal[False]) → Iterator[int]

  • mask (int), yield_lowest_bit (Literal[True]) → Iterator[tuple[int, int]]

  • mask (int), yield_lowest_bit (bool) → Iterator[int] | Iterator[tuple[int, int]]

Uses Kernighan’s algorithm (mask &= mask - 1) to clear the lowest set bit on each iteration, executing only as many steps as there are set bits.

Parameters:

  • mask (int) – A non-negative integer whose set bits will be iterated over.

  • yield_lowest_bit (bool) – If True, yields tuples of (bit_index, lowest_bit_value). If False, yields only the bit_index.

Yields:

int – The zero-based index of the set bit (when yield_lowest_bit is False). tuple[int, int]: A tuple containing (bit_index, lowest_bit_value) where

lowest_bit_value is 2**bit_index (when yield_lowest_bit is True).

Raises:

ValueError – If mask is negative.
