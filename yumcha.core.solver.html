yumcha.core.solver.linear_solver module

Linear solver implementation for deterministic phonetic mapping.

Provides high-performance conversion for schemes with linear field dependencies. Uses regex capture groups to decompose strings into fields, narrows down valid registrants via bitwise mask intersection, and accumulates compatible pattern tuples.
