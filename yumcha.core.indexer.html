class yumcha.core.indexer.Indexer[source]

Bases: object

Manages loading, sorting, bitmask compiling, and index tracking for pattern tuples.

Pattern tuples are sorted by weight upon registration and indexed using bitmasks for each field position to accelerate pattern matching against valid operational directives.

load(pattern_sequences, directions, allowed_directions, reset=False)[source]

Loads, sorts, compiles bitmasks, and extracts charsets for pattern sequences.

Parameters:

  • pattern_sequences (Sequence[Sequence[str | EllipsisType]]) – Sequences of pattern elements representing constraint rules.

  • directions (Sequence[SchemeDirective]) – Conversion directives corresponding to each pattern sequence.

  • allowed_directions (set[SchemeDirective]) – Set of directives permitted during bitmask compilation.

  • reset (bool) – Whether to reset internal state before loading new sequences.

Raises:

ValueError – If pattern_sequences is empty, lengths mismatch directions, sequence slot lengths vary, or all sequences contain wildcards at any single position.

Return type:

None
