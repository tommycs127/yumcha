Loader functions for compiling phonology specifications and scheme mappings.

yumcha.loader.load_phonology(phonology_data)[source]

Loads and compiles a phonology specification from a TSV resource.

Parses table data to build character sets, validation rules, regex tokenization, and a dynamically generated Representation subclass representing language phone structures.

Parameters:

phonology_data (PhonologyData) – A PhonologyData container.

Return type:

Phonology[PhonologyRepresentation]

Returns:

A compiled Phonology instance containing character sets, regex tokenizers, invalid pattern tuples, and dynamic representation classes.

Raises:

ValueError – If lang_id is empty or not a valid Python identifier.

yumcha.loader.load_scheme(scheme_data)[source]

Loads and compiles a orthographic/romanization scheme mapping from a TSV resource.

Parses mapping definitions to construct forward and reverse indexers, regex pattern matchers, and a dynamically generated Representation subclass for the scheme’s field structure.

Parameters:

scheme_data (SchemeData) – A SchemeData container.

Return type:

Scheme[SchemeRepresentation]

Returns:

A loaded Scheme instance.

Raises:

ValueError – If scheme_id is not a valid Python identifier.
